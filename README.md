
# Aplikasi Keranjang Belanja Koperasi Sekolah

## Deskripsi
Aplikasi keranjang belanja koperasi sekolah
berbasis PHP Native dan JSON.

Aplikasi digunakan untuk membantu siswa memilih
barang dan menghitung total belanja sebelum ke kasir.

## Teknologi
- PHP Native
- HTML
- CSS
- JavaScript
- JSON
- XAMPP

## Fitur
1. Menampilkan daftar barang.
2. Tombol tambah barang (+).
3. Tombol kurang barang (-).
4. Menampilkan jumlah barang.
5. Menampilkan halaman keranjang.
6. Menghitung subtotal barang.
7. Menghitung total belanja di controller.
8. Menampilkan harga dalam format Rupiah.
9. Memeriksa stok barang.

## Struktur Penyimpanan
Data barang disimpan dalam:
data/barang.json

Data keranjang disimpan menggunakan:
PHP Session

## Cara Menjalankan
1. Install XAMPP.
2. Jalankan Apache.
3. Simpan folder di dalam htdocs.
4. Buka browser.
5. Akses http://localhost/koperasi-sekolah/
